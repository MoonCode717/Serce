# Serce
Polski program do usuwania Cheatów z gry minecraft. Program obchodzi wszystkie zabezpieczenia oraz szyfruje wszystkie niepotrzebne ślady również w wiekszości ich niezostawia. Program omija kosz oraz logi powershell. Aplikacja wykorzystuje 3-stopniowe szyfrowanie jak i kwantowe zabezpieczenia 512 bitowe przed usunięciem plików
